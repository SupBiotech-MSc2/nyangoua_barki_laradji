# GitHub Course — Guided Exercise Template

This repo is the starting point for the **guided group exercise** used in
Sessions 1 and 2 of the GitHub Course. Each group creates their own
copy of this repo (via GitHub's "Use this template" button) and works through
the exercise together, in groups of 3.

## What's in here

- **`protocol.md`** — a short CRISPR knockout screening protocol. This is the
  file your group will actually edit, commit, branch, and (deliberately)
  conflict over during the exercise. It's a stand-in for a real working
  document — the content itself doesn't matter, only practicing Git on it does.
- **`instructions.md`** — the step-by-step instructions for the exercise: repo setup,
  staging, the add/commit/push/pull loop, undo/rollback, identifying commits,
  branching, merge vs. rebase, and a planted merge conflict to resolve as a
  group. **Don't edit this file** — it's the instructions, not something to
  hand in.
- **`worklog-<yourname>.txt`** (created by each person during the exercise) —
  an individual, per-person log of the Git commands you ran locally. Not
  shared between teammates; each person creates and commits their own.

## Purpose

This exercise is worth 50% of the Group Project grade (shared with the
Session 2 exercise). It's meant to move local Git practice — covered
individually via DataCamp beforehand — into a realistic collaborative setting:
multiple people committing to the same repo, pushing and pulling around each
other, and resolving a real conflict together instead of just reading about
one.

## Getting started

1. Use the "Use this template" button on GitHub to create your group's own
   copy of this repo.
2. Every group member clones the new repo locally.
3. Follow `instuctions.md` from Section 0 onward.
